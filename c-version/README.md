# 智能股票分析与预测系统（C 语言版）

西南财经大学《数据结构（课程设计）》—— 第 1-20 关实现（控制台 + Qt 图形界面）

## 技术栈

- C / C++（MSVC 与 MinGW gcc 双编译器兼容，通过 `portable.h` 适配安全函数差异）
- Qt 6.8.0 msvc2022_64（Qt 图形界面，已下载解压至 `qt/extract/6.8.0/msvc2022_64`）
- 数据存储：文本文件（`stocks.txt` / `entity.txt` / `relation.txt` / `detail/`）

## 使用步骤

### 1. 编译控制台程序（MinGW）

```bash
build.bat
```

要求：`gcc` 已加入 PATH（MinGW）。产物：`output/stock_system.exe`。

### 2. 编译 Qt 图形界面（MSVC + Qt 6.8）

```bash
build_gui.bat        # 或 pwsh build_gui.ps1
pwsh deploy_gui.ps1  # 部署到 output/gui
```

要求：Visual Studio（MSVC x64）+ Qt 6.8.0 msvc2022_64（位于 `qt/extract/6.8.0/msvc2022_64`）。
产物：`output/gui/StockGUI.exe`（双击即可运行，与数据文件同目录）。

### 3. 运行

- **控制台**：运行 `output/stock_system.exe`，或在 `main.c` 中取消对应关卡注释后重新编译
- **GUI**：双击 `output/gui/StockGUI.exe`

> 注意：程序中所有文件名（stocks.txt、detail/ 等）按相对路径读取，
> 需保证可执行文件与数据文件位于同一目录（GUI 的 `main.cpp` 已自动探测并切换工作目录）。

## 关卡说明

### 模块一：股票信息管理与分析（第 1-13 关）

| 关卡 | 功能 | 数据结构/算法 |
|---|---|---|
| 1 | 股票信息存储：输入位置输出该位置股票全部信息 | 顺序表 |
| 2 | 股票信息删除：删除后写回 `new_stock.txt` | 顺序表 |
| 3 | 股票信息修改：修改公司全称后写回 | 顺序表 |
| 4 | 折半查找：先按英文名二路归并排序，再折半查找，输出 ASL | 归并排序 + 折半查找 |
| 5 | 二叉排序树查找：对比原始序列与排序后重建 BST 的 ASL | BST + 快速排序 |
| 6 | 字典树前缀查找：53 子结点（26小写+26大写+空格） | Trie |
| 7 | 开放地址散列查找：线性探测，`Hash=(Σ int(cᵢ)·i²) mod 397`，表长 400 | 散列表 |
| 8 | 链地址散列查找：拉链法（头插法），输出行情明细 | 散列表 + 链 |
| 9 | 链表涨跌额分析：涨跌额<0 前、=0 中、>0 后 | 单链表 |
| 10 | 并查集行业换手率分析：按行业编码 union，汇总换手率 | 并查集 |
| 11 | 堆排序成交量 Top3：指定日期+行业，从大到小 | 堆排序 |
| 12 | 归并排序成交量统计：按日期累加汇总，从小到大 | 归并排序 |
| 13 | 决策树分类统计：二级门类→涨跌幅→成交量三条件分裂 | 决策树（二叉树存储） |

### 模块二：股票信息推荐与预测（第 14-20 关）

| 关卡 | 功能 | 数据结构/算法 |
|---|---|---|
| 14 | 基于规则的实体识别：`*` 匹配任意中文字符 | BF 暴力匹配 |
| 15 | 基于规则的关系抽取：提取两实体间内容与规则集比对 | BF 匹配 |
| 16 | 邻接表知识图谱构建：entity+relation 数据建双向图 | 邻接表（图） |
| 17 | 基于知识图谱的股票推荐：按固定顺序输出关联股票属性 | 图遍历 |
| 18 | 皮尔逊相关系数分析：5 指标与次日涨跌相关性，输出 Top3 | 相关系数 |
| 19 | 朴素贝叶斯涨跌预测（选做）：图结构存高斯参数 | 高斯朴素贝叶斯 |
| 20 | KNN 涨跌幅预测（选做）：Min-Max 归一化 + 欧氏距离 + 有序链表维护 K=3 | KNN |

## Qt 图形界面说明（选做）

`gui_qt/` 提供 5 个功能标签页（与任务书功能模块对应）：

| 标签页 | 功能 |
|---|---|
| ① 信息维护 (1-3关) | 第1关按位置输出、第2关删除、第3关修改 |
| ② 信息查找 (4-8关) | 折半、BST、字典树、开放地址散列、链地址散列 |
| ③ 统计分析 (9-13关) | 链表、并查集、堆排序、归并排序、决策树 |
| ④ 知识图谱 (14-17关) | 实体识别、关系抽取、图谱构建、图谱推荐 |
| ⑤ 股票预测 (18-20关) | 皮尔逊、朴素贝叶斯、KNN |

每个功能面板：输入参数（一行一个）→ 点击「执行」→ 结果输出到文本框。
GUI 通过 `console_capture.cpp` 重定向 stdin/stdout 与 C 函数交互，
与头歌平台评测逻辑完全一致。

## 与 Python + MySQL 版的关系

本目录为 C 语言参考实现，另有同项目的 Python + MySQL 版本位于
`D:\creative\Smart Stock Picking and Prediction System(python+mysql)`。
两者算法逻辑一一对应（`*.c` ↔ `*.py`，`gui_qt/mainwindow.cpp` ↔ `gui.py`），
区别仅在数据存储层：

| 维度 | C 版（本目录） | Python + MySQL 版 |
|---|---|---|
| 数据存储 | 文本文件（stocks.txt 等） | MySQL 8.0（stock_information 库） |
| 数据读取 | `fopen` 直接读文件 | pymysql 查询后构造内存结构 |
| 核心算法 | 手写 C 数据结构（指针） | 手写 Python 数据结构（类） |
| GUI | Qt 6.8 C++ | PySide6 (Qt 6.11) Python |
| 编码 | Windows 控制台 GBK / 文件 UTF-8 | 统一 UTF-8（Python 3 默认） |

两版本均为手写数据结构实现，未用内置库替代算法，满足课程设计考核要求。

## 注意事项

- **编码**：数据文件为 UTF-8 编码；Windows 控制台使用 `chcp 65001` 或
  `SetConsoleOutputCP(CP_UTF8)`（`main.c` 已内置）保证中文显示。
- **编译器**：MSVC 环境使用 Annex K 安全函数；MinGW 环境由 `portable.h`
  自动映射，同一份源码两种编译器均可编译。
- **第 2/3 关**会生成 `new_stock.txt`（写入删除/修改后的股票数据）。
- **第 17 关**依赖第 16 关先构建知识图谱（同一进程内共享全局图结构）。
- **GUI 栈内存**：`MainWindow` 内含 `Stock stocks[400]`（约 1.2MB），
  须在堆上创建（`main.cpp` 已处理），避免超过默认 1MB 栈大小导致栈溢出。
